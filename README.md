# Die Letzte Laterne

Ein eigenes Dark-Fantasy-Open-World-RPG in verpixelter 90er-Optik, das direkt im Browser läuft.
Der Mond schläft seit tausend Jahren nicht mehr, und du trägst die letzte Laterne des Reiches.

## Steuerung

W A S D und Maus zum Laufen und Umsehen, Linksklick oder X zum Angreifen, Rechtsklick zum Blocken,
C zum Rollen, Leertaste zum Springen, Shift zum Rennen, E zum Benutzen, Q für das Reittier.
Auf Handy und Tablet erscheint automatisch eine Touch-Steuerung.

Spielstände bleiben nur im eigenen Browser gespeichert.
